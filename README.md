An original two-sentence horror story, written for make.fun's "Two-Sentence Horror" bounty. A grieving parent reads bedtime stories to an empty bedroom — until one night, something in the dark finishes the story first. The program writes the story to `/output/entry.txt`.

## Run it

```bash
node main.ts
```

It prints the story to stdout and writes it to `/output/entry.txt`.
